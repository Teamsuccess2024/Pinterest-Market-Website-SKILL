**Pin Types: Choosing The Right Format For The Job**

**Why Pin Type Matters**

Pinterest is not a single-format platform. Over the years, Pinterest has rolled out different pin types to compete with TikTok, Instagram, and various ecommerce surfaces. The result is a menu of formats - standard pins, Rich Pins, Idea Pins, Video Pins, Product Pins, Collection Pins - each with different mechanics, different distribution, and different appropriate use cases.

Most users either use only standard pins (missing useful formats) or chase whichever format Pinterest is currently promoting (wasting effort on formats that don't fit their content). The right approach is mechanical: understand what each format does, understand what your content is, and match them. The format is a tool, not a fashion choice.

This file walks through every pin type that matters in 2026, when each one is worth using, and how the format choice affects everything else in the workflow - design, copy, destination, and distribution. By the end, the user should be able to look at any piece of website content and know which pin format (or combination of formats) to produce for it.

A few principles to keep in mind throughout.

The standard pin is still the workhorse. Despite Pinterest periodically promoting newer formats, the static vertical pin linking to an external website remains the format that drives the most outbound traffic. For a website-traffic strategy, standard pins are always the foundation. Other formats are supplements, not replacements.

Format experimentation is real but limited. Pinterest does sometimes give experimental boosts to new formats. Worth participating selectively. Not worth restructuring an entire strategy around.

Outbound clicks remain the holy grail. Some formats - notably Idea Pins in their earlier versions - actively suppressed outbound traffic in favor of keeping users on the platform. The user needs to know which formats drive traffic and which don't, and to weight effort accordingly.

**Standard Pins: The Foundation**

The standard pin is a single static image - typically 1000x1500 pixels, vertical 2:3 aspect ratio - with a title, description, and destination URL. It is what most people picture when they think of a "pin." It is the default. It is the format the entire previous design and copywriting files were written around.

When to use it: almost always.

The standard pin is the right choice for any content that lives on a webpage the user wants traffic to. Blog posts, book pages, product pages, devotionals, free downloads, free resources - all of these should be primarily promoted with standard pins. The standard pin is what every other format is competing with for the user's production time, and in almost every case, the standard pin is the right time investment.

A few advantages of standard pins:

They drive outbound traffic. The whole point of a standard pin is the click. Pinterest's algorithm understands this and routes click-intent searches toward standard pins.

They're fast to produce. With templates in place, a standard pin takes five to ten minutes from idea to published.

They have the longest shelf life. A well-built standard pin can drive traffic for years. Newer formats often have shorter half-lives because they get deprecated or de-emphasized as Pinterest pivots strategies.

They're the format Pinterest's keyword search is best optimized for. Title and description SEO works most reliably on standard pins.

The implication for strategy is simple: 70% to 90% of any user's pin production should be standard pins. The other formats are accents, not the main course.

**Rich Pins: Standard Pins With Superpowers**

Rich Pins are not a separate pin type in the design sense - they're standard pins with extra metadata pulled automatically from the destination website. Once Rich Pins are activated for a domain (covered in the profile-setup file), every standard pin from that domain becomes a Rich Pin automatically. There's no separate workflow for producing them.

What Rich Pins add to a standard pin:

For Article Rich Pins (most relevant for content sites and book libraries): the destination page's headline, author, and meta description appear directly on the pin, even if the user typed nothing into the pin's description fields. This shows up in the feed under the image as bold title text and a short description, drastically improving informativeness without any extra copy work.

For Product Rich Pins: the destination's price and availability are pulled in real time and displayed on the pin. If the price changes on the website, the pin reflects the new price the next time it's seen.

For Recipe Rich Pins: ingredient lists, cook times, and ratings are pulled in.

When to use them: always, on every domain you control. Rich Pins are free, they're automatic, and they meaningfully improve performance. There's no reason not to activate them, and no reason not to ensure every page on the website has the right metadata to make them work.

The practical workflow: activate Rich Pins once per domain via Pinterest's Rich Pins Validator, ensure the destination pages have the right Open Graph or schema.org tags (for WordPress sites with Yoast or RankMath, this is automatic; for custom sites, the developer needs to add the meta tags to the page templates), and then forget about them. Every standard pin from that domain inherits Rich Pin treatment for the rest of the account's life.

For Team Success Network specifically, Article Rich Pins are the right configuration. Each book page should have a clear headline tag, an author tag, and a meta description that summarizes the book. Once the metadata is in place, every pin pointing to a book page gets the auto-formatted overlay treatment in the feed - which is a massive click-through advantage versus competing pins that don't have Rich Pins activated.

**Idea Pins: The Native Story Format**

Idea Pins (formerly called "Story Pins") are Pinterest's answer to TikTok and Instagram Reels - a multi-page format that combines images, video, and text into a swipeable story. The user creates a sequence of pages, each with text and visuals, and the viewer swipes through the sequence within Pinterest itself.

A few critical things to know about Idea Pins.

**Idea Pins do not link out to external websites.** This is the single most important fact about the format. When a user views an Idea Pin, there is no clickable URL that takes them to a destination website. They consume the content inside Pinterest and move on. Idea Pins are designed to keep users on the platform, not send them off it.

This means Idea Pins are fundamentally not a traffic format. They build brand awareness, they grow followers, they signal to Pinterest's algorithm that the account is producing native content - but they do not directly drive website visits.

**Idea Pins do influence overall account distribution.** Pinterest gives some preferential treatment to accounts that publish Idea Pins. The signal seems to be: "this account is producing native, engaging content, so we'll show their other pins (including standard pins) to more users." The lift is real but modest.

**Idea Pins have multi-page formats with limits.** Each Idea Pin can have up to 20 pages. Each page can be an image, a short video, or a text overlay. The total length of any video segments is capped at around 60 seconds.

When to use them: occasionally, as a brand-building supplement to a primary standard-pin strategy. A reasonable ratio is one Idea Pin for every 10 to 20 standard pins. The Idea Pin builds account-level signal; the standard pins drive the actual traffic.

What works well in Idea Pin format:

Multi-step how-to content. "How to Build a Daily Devotional Habit" works well as a five-page Idea Pin walking through the steps. Each page covers one step.

Numbered list content. "5 Bible Verses for Anxious Mornings" can be five pages, one verse per page. Visually consistent across the sequence.

Behind-the-scenes content. A glimpse of the user's writing process, their library, their devotional setup. Builds brand connection without requiring a direct sales pitch.

Brand introductions. A short Idea Pin introducing the website, the mission, and what the user offers. Functions as a kind of mini "about" pin.

What doesn't work well in Idea Pin format:

Anything where the goal is the click. If the user wants traffic to a specific page, a standard pin is the right format. Period.

Heavily text-driven content. Idea Pins are designed for short, glanceable text. Long-form writing belongs on the destination page, with a standard pin pointing to it.

Content that's a one-pager. If there's only one image and one idea, it's a standard pin, not an Idea Pin.

For Team Success Network specifically, Idea Pins are useful for occasional brand-awareness content - a multi-page walk-through of "5 Books to Read When Life Feels Heavy," for example, or an Idea Pin teaching "How to Start Your First Daily Devotional," with a soft mention of the free library at the end. These build brand recognition. They don't replace the standard pins that actually drive book downloads.

A practical recommendation: budget one or two Idea Pins per month, use them for high-value brand content, and don't sweat the format beyond that. Most of the production effort stays on standard pins.

**Video Pins: The Hybrid Format**

Video Pins are standard-format pins (vertical 2:3) where the visual element is a short video instead of a static image. They link out to external websites just like standard pins do. They are, in essence, standard pins with motion.

This is an important distinction from Idea Pins. Video Pins are traffic-driving. Idea Pins are not.

When to use them: when the content benefits from motion, and when the user has the production capacity to produce video at scale.

Pinterest occasionally gives Video Pins distribution boosts, particularly in feed surfaces where motion catches the eye more than static images. For accounts that can produce video content well, Video Pins can outperform static pins in the same content category. For accounts that can't, the production cost-to-benefit ratio is bad - a mediocre video pin underperforms a strong static pin almost every time.

What works well as a Video Pin:

Looping animation of typography. A scripture verse that animates in line by line, then loops. Six to ten seconds. Simple, repeatable, eye-catching.

Short product demos. Showing a book's pages flipping, a journal being written in, a Bible being opened. Lifestyle motion that signals what the content is about.

Brief teaser content. A 10-second video that hints at a longer piece on the destination page - "5 truths you need to hear about putting God first" with quick text frames, then a CTA to read more on the website.

What doesn't work well:

Long videos. Pinterest viewers don't watch long-form video on the platform. Video Pins should be 6 to 15 seconds, max 30 seconds. Anything longer is wasted production effort.

Talking-head videos. Pinterest viewers scroll without sound by default. Talking-head content with audio-dependent meaning fails almost universally. If video needs to communicate without sound, design accordingly.

Low-production-quality video. A blurry phone video looks worse on Pinterest than even a basic static graphic. The bar for video quality is higher than for static images, because motion pulls more scrutiny.

For Team Success Network specifically, Video Pins are an occasional supplement, not a core format. If the user can produce a 10-second looping scripture animation in Canva or a similar tool, a few Video Pins per month could meaningfully boost certain pieces of content. But Video Pins should never come at the cost of static pin production. The ratio should be: 90% static, 10% video, max.

A practical note: Pinterest's video specs change occasionally. As of 2026, Video Pins should be 6-15 seconds for best performance, MP4 format, 1000x1500 dimensions, under 2GB file size. The user should verify current specs at Pinterest's business help center before producing video content for the first time.

**Product Pins: For Anything With A Price Tag**

Product Pins are a subtype of Rich Pin specifically for ecommerce. When the destination page has product schema markup (price, availability, product name, description), Pinterest pulls that data directly into the pin and displays it in real time.

This means Product Pins automatically show:

The current price.

Whether the product is in stock.

A direct link to the product page.

A product description.

When the price changes on the website, every Product Pin pointing to that product updates automatically the next time the pin is rendered.

When to use them: for any product the user is selling. If the website has a store, Product Pins are the right format for store pages. The auto-pricing is enormously valuable both for visual appeal in the feed and for search filtering - Pinterest's "shopping" search surfaces preferentially feature pins with valid product schema.

The implementation requirement is the destination page needs valid product schema markup. For Shopify, WooCommerce, BigCommerce, and other major ecommerce platforms, this is automatic. For custom-built ecommerce (which fits some of the user's PHP/MySQL planning), the developer needs to add product schema tags to the product templates. Once the schema is in place, Pinterest reads it the same way Google reads it for shopping ads.

For Team Success Network specifically, Product Pins become relevant when the planned ebook shopping cart system goes live. The free book downloads don't need Product Pins - Article Rich Pins serve them well - but the future paid ebook offerings should be set up with product schema from day one. Every paid book becomes a candidate for Product Pin treatment, which makes the entire library more shoppable on Pinterest.

A note on shoppable pins and Pinterest's shopping ecosystem: Pinterest has been pushing hard on shopping integrations for several years, and the shopping search results surface more product pins than ever. Accounts that have product pins set up correctly get preferential treatment in shopping search. Accounts that don't get filtered out of those surfaces entirely. For ecommerce-adjacent businesses, this is not optional - it's a baseline competitive requirement.

**Collection Pins: Multi-Image Showcases**

Collection Pins are a hybrid format where a hero image is paired with several smaller images underneath, all in a single pin. The hero image dominates; the smaller images function as a kind of preview gallery. Each image in the collection can link to a different destination URL.

When to use them: rarely, but with specific use cases.

Collection Pins work well when the user wants to showcase a curated set of related items. For ecommerce, this could be "5 products in our fall collection" - one hero image of the collection, five smaller images each linking to a specific product. For content sites, this could be "Our 5 most-read devotional books" - one hero image of a stack of books, five smaller images each linking to a specific book page.

The format is more complex to set up than standard pins and the distribution lift over a comparable standard pin is modest at best. For most accounts, Collection Pins are not worth the extra production effort.

For Team Success Network specifically, Collection Pins could be useful for occasional "category showcases" - a Collection Pin for "Free Christian Books on Suffering" with the user's three or four titles on that theme, each linking to its own page. These could function as a kind of category landing page within Pinterest itself. Worth experimenting with quarterly, not weekly.

**Carousel Pins: A Quick Note**

Pinterest at various times has supported a carousel format where a single pin contains multiple swipeable images. This format has been deprecated and re-introduced over the years and is currently de-emphasized in 2026 in favor of Idea Pins (for native content) and Collection Pins (for product showcases).

If the user encounters references to Carousel Pins in older Pinterest tutorials, they can mostly be ignored. The functional equivalents are Idea Pins (for sequential storytelling) and Collection Pins (for product or content showcases).

**Format Selection: The Decision Framework**

Putting all of this together, here's a simple decision framework for any new piece of content the user wants to promote on Pinterest.

**Step one: is the goal traffic to a website page?**

If yes, default to standard pins. Produce three to five standard pin variants.

If the destination is a product with a price, ensure Product Rich Pins are active for the page. The standard pin format becomes a Product Pin automatically once the schema is in place.

If the destination is an article or book page, ensure Article Rich Pins are active for the domain. The standard pin format becomes an Article Rich Pin automatically.

**Step two: is the content multi-step or list-based, and would a sequence of glanceable pages add value?**

If yes, also produce one Idea Pin as a brand-building supplement. The Idea Pin won't drive direct traffic but will boost overall account distribution. Use one of the standard pin variants in the sequence to remain visible in search.

If no, skip the Idea Pin. Don't force the format.

**Step three: does the content benefit from motion, and does the user have video production capacity?**

If yes, produce one Video Pin as an additional standard-pin variant. Video Pins drive traffic like static pins, with a possible distribution boost.

If no, skip the video. Don't produce low-quality video for Pinterest.

**Step four: is this a curated collection of related items, each with its own destination URL?**

If yes, consider a Collection Pin alongside the individual standard pins. The Collection Pin functions as a kind of branded gallery.

If no, skip it.

For most pieces of content on a typical content site, the answer to this framework is: "Three to five standard pins, all benefiting from Article Rich Pin metadata, and that's it." Idea Pins, Video Pins, and Collection Pins are occasional supplements for specific content types, not regular features.

**A Worked Example: Format Selection For The Crown Of Thorns Book**

To make this concrete, here's how the format selection plays out for the Team Success Network book on Jesus choosing the crown of thorns.

The destination is a book page on TeamSuccessNetwork.com offering a free download. The page has an Article Rich Pin-compatible setup - headline, meta description, author tag.

Standard pin production: five variants, as established in the design and copywriting files. Each variant targets a different layer-three keyword angle, uses one of the four templates, includes the right title and description copy, and links to the same book page. Each variant becomes an Article Rich Pin automatically because of the domain's metadata.

Idea Pin production: one Idea Pin titled "5 Reasons Jesus Chose the Crown of Thorns," with five pages, one reason per page. Each page has a clean visual treatment in the brand's dark-and-gold aesthetic, with bold typography. The final page includes a soft CTA mentioning the free book at TeamSuccessNetwork.com - though this won't be a clickable link, the brand mention plants the seed for users to search the brand later.

Video Pin production: skipped. The user has not yet built video production capacity. Producing low-quality video would be worse than producing no video. The standard and Idea Pins do the job.

Collection Pin production: skipped for this individual book. A Collection Pin showcasing "Free Christian Books on Suffering" - featuring this book and two or three others on the theme - could be produced separately as a category-level pin, but that's a different pin from the individual book promotion.

Product Pin production: not applicable. The book is a free download, not a priced product. If the book becomes paid in the future, Product Pin schema becomes worth implementing.

The total format mix for this single piece of content: five standard Article Rich Pins plus one Idea Pin. Six total Pinterest assets. Five of them drive direct traffic. One supports overall account distribution and brand recognition.

This is the kind of format mix that should be the user's default for major pieces of content. For lower-priority content, three standard pins might be sufficient. For signature pieces, the full mix is worth the time.

**Maintaining Format Awareness Over Time**

Pinterest's format priorities shift. The platform occasionally promotes new formats, deprecates old ones, and changes the algorithmic weight of each. The user should not chase every trend but should periodically check in on what's working.

A reasonable cadence: every six months, spend an hour reading Pinterest's official business blog and a handful of independent Pinterest marketing sources to see if format priorities have shifted. If a new format has been launched, evaluate whether it fits the content. If an existing format has been de-emphasized, adjust the production mix accordingly.

What not to do: jump on every new format the day it launches, restructure the entire production workflow around it, and discover three months later that Pinterest has quietly moved on to the next thing. The standard pin has been Pinterest's foundation for over a decade. New formats come and go around it. The standard pin endures.

**Common Format Mistakes To Avoid**

A few patterns appear constantly when users misuse pin formats. Recognize and avoid them.

**Producing only Idea Pins because they "feel like the future."** Idea Pins don't drive outbound traffic. An account that produces only Idea Pins gets followers and brand awareness but very few website visits. For a website-traffic strategy, this is a fundamental mismatch.

**Skipping Rich Pins because they "seem complicated."** Rich Pins are a one-time setup that benefits every standard pin from a domain forever. Skipping them is leaving free distribution on the table for no reason.

**Producing video for the sake of video.** Low-quality video underperforms strong static pins. The bar for video is higher than for static, not lower. Don't produce video unless it's actually good.

**Using Collection Pins as the primary format.** Collection Pins are a niche supplement, not a workhorse. Accounts that try to use them as a primary format usually find production overhead doesn't match the distribution lift.

**Ignoring Product Pins on ecommerce pages.** Any priced product without Product Rich Pin schema is invisible to Pinterest's shopping search surfaces. This is a baseline competitive requirement, not a nice-to-have.

**Confusing pin format experimentation with strategy.** Trying every format once is fine. Restructuring strategy based on whichever format is currently being promoted is not. The strategy is: standard pins as workhorse, other formats as targeted supplements. The format decisions follow from the content, not from Pinterest's roadmap.

**What This Means For The Workflow**

By the end of this file, the user should be able to:

Default to standard pins for almost all content, treating other formats as supplements.

Activate Rich Pins on every domain they control, ensuring the metadata supports automatic enrichment of standard pins.

Produce occasional Idea Pins as brand-building supplements, without expecting traffic from them.

Produce Video Pins selectively, only when content benefits from motion and production quality is high.

Implement Product Pins for any priced product, as a baseline requirement for ecommerce visibility.

Use Collection Pins sparingly, for specific curated showcases.

Re-evaluate format priorities every six months, without chasing every Pinterest trend.

Avoid the common mistakes that come from misallocating production effort across formats.

The format choice is a tool, not a fashion. Match the format to the content and the goal. Default to the standard pin until there's a specific reason to do otherwise. Let Rich Pins do their automatic work in the background. Use the rest of the format menu sparingly, intentionally, and never at the cost of standard pin production.

The standard pin is what made Pinterest what it is. It remains the format that drives the most traffic to the most websites. Every other format orbits around it. Build accordingly.
